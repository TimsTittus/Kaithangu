# Demo accounts

Everything created by `bun run db:seed` is **fictional demo data**: societies and
the federation are labelled "(Demo)", and people's names are generated by faker
(seed 42). Do not use real people's phone numbers in the seed.

Login uses phone OTP (implemented in a later phase). In mock mode OTPs are written
to `DEV_INBOX` instead of being sent.

## Fixed phones

| Role              | Phone                             | Scope                                             |
| ----------------- | --------------------------------- | ------------------------------------------------- |
| customer          | `+919000000001`                   | Kerala; one saved address at the demo pincode     |
| lcs_admin         | `+919000000010` … `+919000000014` | one per demo society, in seed order (society 1–5) |
| state_admin       | `+919000000020`                   | Kerala (`KL`)                                     |
| national_admin    | `+919000000030`                   | national (NCCT)                                   |
| institution_admin | `+919000000040`                   | "Demo Government School (Demo)", Kerala           |

Societies 1–3 are in Ernakulam district and 4–5 in Kottayam district. Each is
placed at the centroid of a pincode picked from `data/raw/pincodes.csv`; the seed
prints which pincodes were chosen.

## Workers

- 500 synthetic workers, 100 per society, phones `+919000100000` … `+919000100499`.
- 30 % have no smartphone (IVR only), 10 % are `pending`, the rest `verified`.
- Homes are random points within 4 km of their society.

## Physical keypad phones

Set these in `.env` before seeding (E.164). They are optional; when empty the seed
skips them with a warning.

| Variable              | Seeded as                                                           |
| --------------------- | ------------------------------------------------------------------- |
| `DEMO_WORKER_PHONE_1` | verified plumber, level 3, keypad only, available                   |
| `DEMO_WORKER_PHONE_2` | verified **certified** electrician, level 3, keypad only, available |

Both live within 1 km of `DEMO_PINCODE` and belong to the nearest demo society.
`DEMO_PINCODE` must exist in the imported pincode table; when it is empty the seed
uses society 1's pincode and prints it.
